# Criterios de Aceptación Técnicos

## Controller Layer
- [ ] Endpoint implementado
- [ ] Validación de request
- [ ] Códigos HTTP correctos

## Service Layer
- [ ] Lógica de negocio encapsulada
- [ ] Validaciones de dominio
- [ ] Transacciones manejadas

## Repository Layer
- [ ] Queries optimizadas
- [ ] Filtro por `notary_id`
- [ ] Métodos CRUD

## Entity/DTO
- [ ] Entity con propiedades tipadas
- [ ] DTOs Request/Response
- [ ] Mappers

## Tests
- [ ] Unit tests para Service
- [ ] Integration tests para Repository

## Código
- [ ] PSR-12 style
- [ ] Typed properties
- [ ] SOLID aplicado

## Performance
- [ ] Queries con índices
- [ ] Sin N+1 queries
- [ ] Paginación donde aplique

## Seguridad
- [ ] JWT requerido
- [ ] Multi-tenant validado
- [ ] Input sanitizado
